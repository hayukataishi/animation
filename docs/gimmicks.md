# ギミックアイテム仕様書

## 1. ぐるっとスワイプ (Circle Swipe)

### 概要
画面上に円を描くようなジェスチャー（スワイプまたはドラッグ）を行うことで、ページ全体のテーマやデザインモードを切り替えるインタラクティブなギミック。

### 仕様詳細
- **ID**: `circle-swipe`
- **タイトル**: ぐるっとスワイプ
- **対応デバイス**:
  - `PC` (マウスドラッグ)
  - `Phone` (タッチスワイプ)
- **動作**:
  1. 画面上の任意の場所（あるいは指定エリア）で、ユーザーが円を描くように入力を開始する。
  2. 一定以上の角度（例: 360度近い回転）や距離を検知すると、トリガーが発動する。
  3. トリガー発動時、トランジションアニメーションと共に背景色や要素のスタイルが切り替わる（例: ダークモード ⇔ ライトモード、あるいは全く別のテーマ）。
- **実装イメージ**:
  - SVGやCanvasで軌跡を表示する演出を入れると操作感が向上する。
  - 回転量を計算し、しきい値を超えたらアクションを実行。

## 2. 水面タップ (Water Ripple)

### 概要
画面をクリックまたはタップした位置を中心に、水面に波紋が広がるようなリアルなエフェクトを表示する背景演出ギミック。

### 仕様詳細
- **ID**: `water-ripple`
- **タイトル**: 水面タップ
- **対応デバイス**:
  - `PC` (マウスクリック)
  - `Phone` (指タップ)
- **動作**:
  1. ユーザーが画面上の任意の場所をクリック/タップする。
  2. その座標を中心として、波紋（Ripple）のエフェクトが生成され、外側へ広がって消えていく。
  3. 連続タップにも対応し、複数の波紋が干渉し合うような表現が望ましい。
  4. 背景画像自体を歪ませるシェーダー表現（WebGL/Three.js等）または、Canvas/CSSによる簡易表現のいずれかを採用。
- **実装イメージ**:
  - WebGLを使用すると高品質な屈折表現が可能。
  - パフォーマンスを考慮し、Canvas 2Dでの実装も検討の余地あり。
